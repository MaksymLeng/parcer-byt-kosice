# FlatWatch Košice

Монитор новых объявлений об аренде в Кошице: Bazoš, Facebook, Jozue и Nehnutelnosti.sk.

Текущие фильтры:

- аренда, 2 или 3 комнаты (`2-izbový`, `3-izbový`);
- двух- и трёхкомнатные 500–800 €;
- предложения комнат/подселения в существующее жильё до 750 €;
- предложения только для девушек и поиск жилья исключены;
- весь Košice;
- Železníky, Centrum и Staré Mesto отмечаются как приоритет;
- уведомления приходят в Telegram;
- объявления дедуплицируются по ID и содержимому между источниками. Поднятый `TOP` не приходит повторно; для объявлений с разным текстом одного и того же объекта совпадение не гарантируется.
- объявления старше 48 часов не отправляются, даже если их снова подняли в выдаче;
- первое сканирование каждого источника создаёт базовую отметку без рассылки старых публикаций.

## Быстрый запуск Bazoš

Python 3.11+ и пакет `requests`:

```bash
python3 -m pip install -r requirements.txt
cp .env.example .env
```

Создайте бота через `@BotFather`, внесите токен в `.env`, напишите боту `/start`, затем получите chat ID:

```bash
.venv/bin/python -m flatwatch telegram-configure
```

Команда скрывает токен во время ввода, сама определяет chat ID и сохраняет оба значения в `.env` с правами `600`. После этого выполните первую проверку:

```bash
python3 -m flatwatch check
```

Первый запуск создаёт базовую отметку и не отправляет старые объявления. Для отправки уже существующих подходящих вариантов используйте `--notify-existing`.

Постоянный мониторинг с интервалом из `config.json`:

```bash
python3 -m flatwatch run
```

Шаблоны user-сервисов находятся в `deploy/`. Задержка после завершения обхода:
Bazoš — 5 минут, Facebook, Jozue и Nehnuteľnosti — 15 минут. Полный период включает время обхода.

Выгрузка подходящих публикаций за последние 48 часов для ручного просмотра:

```bash
.venv/bin/python -m flatwatch history --hours 48 --output data/last-48h.md
```

Эта команда глубже прокручивает Facebook-группы, проверяет Bazoš и Jozue и не отправляет
ничего в Telegram и не меняет состояние основного монитора.

## VPS через Docker Compose

На сервер переносятся код, `.env`, `data/` и постоянный Facebook-профиль. Запуск:

```bash
docker compose -f docker-compose.vps.yml up -d --build
docker compose -f docker-compose.vps.yml ps
```

Четыре независимых контейнера: `bazos`, `facebook`, `jozue` и `nehnutelnosti`.
После завершения обхода Bazoš ждёт 5 минут, остальные — 15 минут.
Все используют `restart: unless-stopped`; каждый собирает только свой источник и
общую SQLite-базу. Новому источнику нужен отдельный первый обход без рассылки старых
объявлений — не используйте `--notify-existing` при его включении.

Bazoš обходит страницы всех настроенных запросов, включая отдельную категорию
`Podnájom, spolubývajúci`. Nehnutelnosti.sk читает все страницы результатов
`/vysledky/byty/kosice/prenajom` и оригинальную дату `validFrom`, не дату
поднятия объявления. Оба источника сообщают об ошибке при превышении лимита страниц
вместо молчаливого усечения. Проверка без Telegram и изменения рабочей базы:

```bash
.venv/bin/python -m flatwatch history --no-facebook --no-jozue --hours 48 --output data/web-last-48h.md
```

Наличие объявления в базе подтверждает только то, что оно прошло фильтры и было
сохранено; исторические объявления, не увиденные парсером, из базы восстановить
нельзя. Facebook-группы без доступа, группы с нулём видимых постов, текст на
изображениях и нераскрытые посты требуют отдельной ручной проверки.

При добавлении Jozue к уже работающему серверу после резервного копирования и
переноса кода/конфигурации достаточно:

```bash
docker compose -f docker-compose.vps.yml build jozue
docker compose -f docker-compose.vps.yml up -d --no-deps jozue
docker compose -f docker-compose.vps.yml logs --tail 50 jozue
```

Это не перезапускает Bazoš/Facebook. Старые контейнеры могут продолжать использовать
предыдущий образ; добавляемая колонка SQLite `metadata` совместима с их кодом.
Не используйте `--notify-existing` для первого запуска: существующие объявления
не должны становиться новой массовой рассылкой.

## Jozue

Публичный каталог `https://www.jozue.sk/prenajom-nehnutelnosti`, без логина.
Обходятся все страницы (защитный лимит 10 страниц; превышение вызывает ошибку,
а не молчаливое усечение). Для квартир и комнат читается полная карточка.

- Возраст определяется по `Pridané` с часовым поясом Europe/Bratislava, не по дате
  первого обнаружения. Публикации старше 48 часов не рассылаются.
- Слова `PRENAJATE`, `prenajaté`, `REZERVOVANE` в названии или метках означают,
  что объект недоступен, даже если поле `Status` всё ещё содержит `aktívne`.
- Город и тип недвижимости берутся из полей карточки. Košice-okolie, дома,
  коммерческие объекты, продажа и посуточная аренда исключены.
- Цена берётся из ценового поля, не из суммы депозита. Если явно подписанная
  аренда в описании отличается, используется большая сумма и показывается
  предупреждение о расхождении. Известные доплаты за
  коммунальные проверяются общим фильтром; неизвестные нужно уточнить у агентства.
- HTTP-ошибка, неожиданная разметка, пропавшая дата или неполная карточка
  прерывают обход с уведомлением в Telegram; восстановление также уведомляется.
- Решения последнего обхода сохраняются в `data/latest-jozue-review.json`.

Проверка **только Jozue**, без отправки и без изменения основной базы:

```bash
.venv/bin/python -m flatwatch history --no-bazos --no-facebook --no-nehnutelnosti --hours 48 --output data/jozue-last-48h.md
```

Флаги `--no-jozue` и `--no-nehnutelnosti` исключают соответствующий источник из
`check`, `run` и `history`.
`check --no-telegram` всё равно меняет состояние базы; для read-only просмотра
используйте `history`. Постоянный локальный сервис не нужен, если монитор работает на VPS.

## Facebook

Facebook подключается через отдельный постоянный профиль браузера. Пароль в конфигурации не хранится.

Подключены 25 групп Košice: профильные словацкие и англоязычные группы аренды,
а также локальные украинские сообщества. Фильтры: целые 2- и 3-комнатные
квартиры за 500–800 €, а также предложения комнат/подселения в уже существующее
жильё до 750 € без нижнего порога. Предложения только для девушек исключены;
нейтральные предложения допускаются. Поиск жилья, совместный поиск квартиры,
продажа, однушки целиком и посуточная аренда исключены.

Сборщик читает текст самого поста без комментариев, раскрывает «Ещё» и при
необходимости открывает публикацию отдельно. Обычный обход использует новые
публикации и четыре прокрутки на группу. Закрытые группы без доступа, посты
только на картинках и публикации без подтверждаемой даты не гарантируют покрытие.
Возраст считается по дате публикации, а не появления в поиске; относительная
дата Facebook приблизительная. При сбое проверки Telegram получает уведомление,
повтор не чаще раза в 6 часов; после успешного обхода приходит восстановление.

Ручной аудит (без Telegram):

```bash
.venv/bin/python -m scripts.audit_facebook --output data/audit.json --scrolls 8
.venv/bin/python -m scripts.enrich_audit --input data/audit.jsonl --output data/audit-details.json
```

Для отправки ранее проверенного JSON со структурами Listing используется
`scripts/backfill_facebook.py --input ... --hours 48 --send`. Без `--send`
создаётся только отчёт. На VPS скрипт монтируется в `/app/backfill_facebook.py`;
перед отдельным браузерным обходом плановый Facebook-контейнер нужно остановить.

```bash
.venv/bin/pip install -r requirements-facebook.txt
PLAYWRIGHT_BROWSERS_PATH=browser-profile/ms-playwright .venv/bin/python -m playwright install chromium
.venv/bin/python -m flatwatch facebook-login
```

В открывшемся окне войдите в аккаунт и вступите в нужные группы. После проверки сессии переключите `sources.facebook.enabled` в `config.json` на `true`. Селекторы Facebook могут меняться; перед постоянным запуском канал нужно проверить на реальном аккаунте.
